# Blinkit Sales Analysis

## Overview
This project analyzes Blinkit grocery sales data using Python and Pandas to uncover sales trends and business insights.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
